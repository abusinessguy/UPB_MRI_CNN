# MRI Brain Tumor CNN Classification

Deep learning project for classifying MRI brain scans using a convolutional neural network.

## Overview

This project applies CNN-based image classification to MRI brain scan data for tumor detection. The goal is to build a reproducible training pipeline and evaluate model performance on medical image data.

## What I Built

- Image loading and preprocessing workflow
- CNN model for MRI classification
- Training and validation loop
- Performance evaluation workflow

## Tech Stack

Python, PyTorch, NumPy, Matplotlib
